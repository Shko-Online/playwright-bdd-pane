# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
**Security → Report a vulnerability** on
[this repository](https://github.com/Shko-Online/playwright-bdd-pane/security/advisories/new).

Do not open a public issue. Include the extension version, the steps to reproduce, and the
impact you expect. You will get an acknowledgement within a few days, and a fix will be
released to the Visual Studio Marketplace before the issue is disclosed.

## Supported versions

Only the latest version published to the Marketplace receives security fixes.
